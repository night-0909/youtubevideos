# youtubevideos
Extract videos informations and playlists with comments

videos.py : extract informations and thumbnail of videos of a Youtube channel<br />
playlist_APIV3.py : extract playlist informations and their videos comments

scrapetube module : I made some changes to fix some issues. See my version : https://github.com/night-0909/scrapetube

videos.py accept cookies from Youtube account.<br />
You'll have better results if you use cookies : bypass bot detection, rate limits, access to members-only content, login required content.<br />
Procedure to export cookies from Youtube : read https://github.com/yt-dlp/yt-dlp/wiki/Extractors#exporting-youtube-cookies and https://github.com/yt-dlp/yt-dlp/wiki/FAQ#how-do-i-pass-cookies-to-yt-dlp
